# ЛР3 — Псевдослучайные генераторы

## Что реализовано

| № | Генератор                   | Идея                                                              |
|---|-----------------------------|-------------------------------------------------------------------|
| 1 | **LCG_Xor**                 | Линейный конгруэнтный генератор + xor-перетряска старших и младших бит. |
| 2 | **MidSquare_Improved**      | Метод среднего квадрата фон Неймана + сложение со счётчиком (защита от вырождения). |
| 3 | **XorShift32_StarPlus**     | Канонический xorshift32 + финальное умножение и сложение счётчика. |
| 4 | `std::mt19937` (для сравнения) | Стандартный «вихрь Мерсенна» из заголовка `<random>`.            |

Реализация — [src/prng.h](src/prng.h).

## Что считаем

1. **20 выборок** на каждый генератор, **по 1000 чисел** в диапазоне `[0; 5000)`
   ([src/main.cpp](src/main.cpp) → команда `samples`).
2. Для каждой выборки — **среднее, σ, коэффициент вариации, критерий χ²** на
   равномерность по 20 интервалам ([scripts/analyze.py](scripts/analyze.py)).
3. **NIST-тесты** (5 штук — monobit, block frequency, runs, longest run,
   cumulative sums) на «сыром» 1 МБ бит-потоке от каждого генератора
   ([scripts/nist_tests.py](scripts/nist_tests.py)).
4. **Время генерации** для n от 1000 до 1 000 000 — наши три против
   `std::mt19937` ([results/plot_time.png](results/plot_time.png)).

## Запуск

```cmd
cd LR3
build.bat

:: 60 выборок + 3 файла с битами для NIST
build\lr3.exe samples results\samples

:: статистика по выборкам и χ²
python scripts\analyze.py results\samples results\stats.csv

:: NIST-тесты
python scripts\nist_tests.py results\samples results\nist_results.csv

:: бенч скорости
build\lr3.exe bench results\bench.csv
python scripts\plot_results.py results\bench.csv results\plot_time.png
```

## Результаты

### χ² на равномерность (5%-уровень, df=19, критическое значение 30,144)

См. [results/stats_summary.csv](results/stats_summary.csv).

| Генератор             | Среднее (ожидалось 2500) | CV, %  | Среднее χ² | Прошло из 20 |
|-----------------------|--------------------------|--------|------------|--------------|
| LCG_Xor               | 2499,3                   | 57,5   | 23,0       | 17           |
| MidSquare_Improved    | 2500,0                   | 57,2   | 19,5       | 19           |
| XorShift32_StarPlus   | 2480,3                   | 58,2   | 17,8       | 20           |

Все три генератора по χ² ведут себя как «достаточно равномерные»: для
**равномерного** распределения на отрезке (0; R) теоретический CV ≈ 57,7 %,
наши CV совпадают с этим до десятых.

### NIST-тесты (5 тестов × 3 генератора, p ≥ 0,01 = прошло)

См. [results/nist_results.csv](results/nist_results.csv).

| Генератор             | monobit | block_freq | runs | longest_run | cumsum | пройдено |
|-----------------------|---------|------------|------|-------------|--------|----------|
| LCG_Xor               | PASS    | PASS       | PASS | PASS        | PASS   | 5/5      |
| MidSquare_Improved    | PASS    | PASS       | PASS | PASS        | PASS   | 5/5      |
| XorShift32_StarPlus   | PASS    | PASS       | PASS | PASS        | PASS   | 5/5      |

**Все три генератора прошли все пять NIST-тестов** на потоке в 1 МБ.
Результат согласуется с χ²-выводом: распределение равномерное, нет
очевидных корреляций между соседними битами.

### Скорость генерации

См. [results/plot_time.png](results/plot_time.png).

* `LCG_Xor` — самый быстрый (примерно в 1.5–2 раза быстрее `std::mt19937`),
  так как состоит из 2 умножений и пары xor.
* `XorShift32_StarPlus` — на ~10–20 % быстрее `mt19937`.
* `MidSquare_Improved` — сравним с `mt19937` (на больших объёмах чуть
  медленнее: умножение 64×64 + перетряска бит).

## Выводы

Модификации классических методов (LCG, средний квадрат, xorshift) дают
вполне рабочие генераторы: они быстро работают, проходят χ² на равномерность
и проходят базовый набор NIST-тестов. Тем не менее для криптографических
целей этого недостаточно — для них стандартно используют CSPRNG (`ChaCha20`,
`AES-CTR DRBG` и т. д.).
